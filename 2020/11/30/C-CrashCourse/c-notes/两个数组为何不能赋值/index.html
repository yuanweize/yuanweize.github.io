数组变量 是 const 的指针

&arr 竟然与 arr 与 q 是一样的！ 为什么会 这样？&arr 与 arr 有什么区别？请看下面的程序：

&arr + 1 和 arr + 1差了 12 个字节， 刚好是一整个arr数组的长度。这意味着什么？

取数组的地址 实际上 取走的是 ==整个数组==的 地址，它将整个数组视为整体，对它进行加减，大小是整个数组的大小
