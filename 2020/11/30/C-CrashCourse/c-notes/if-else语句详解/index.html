上面两种写法有区别吗？

总结

  • 多个if 并列 程序会遍历所有的 if 条件。最后一个 else 与最后一个 if 配对，两者必有一个为真
  • 多个 else if 并列 程序只要找到一个 真，就会退出整个 “条件体”。最后一个else 与 前面的任意一个语句 必有一个为真。
  • 关于else：
    • 第一种：else 与 最后一个 if 形成对立
    • 第二种：else 与 除 else 外的整体形成对立
