type

显示指定命令的类型。

概要

主要用途

  • 显示要查找的命令的信息。
  • 控制查找范围和行为。
  • 显示要查找的命令优先级最高的类型。

选项

参数

name：要查找的命令，可以为多个。

返回值

当指定的命令可以找到时返回成功，如果有没找到的返回失败。

注意

  1. 该命令是bash内建命令，相关的帮助信息请查看help命令。

  2. 命令优先级问题请查看builtin命令。
