return

从函数中退出并返回数值。

概要

主要用途

  • 使得shell函数退出并返回数值，如果没有指定n的值，则默认为函数最后一条命令执行的返回状态。

参数

n（可选）：整数。

返回值

返回值为你指定的参数n的值，如果你指定的参数大于255或小于0，那么会通过加或减256的方式使得返回值总是处于0到255之间。

在函数外执行return语句会返回失败。
