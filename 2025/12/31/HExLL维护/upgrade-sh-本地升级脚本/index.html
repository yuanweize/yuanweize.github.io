tools/upgrade.sh：本地升级依赖与主题（并重新生成）

发表于31-12-2025|更新于31-12-2025|HExLL维护
|总字数:438|阅读时长:1分钟|浏览量:

tools/upgrade.sh 面向的是本地开发机：当你想“刷新依赖 + 更新 Butterfly 主题 + 重新生成站点”时，一条命令跑完。

用法

在仓库根目录执行：

  • bash tools/upgrade.sh

执行结束后：

  • 本地预览：npm run server
  • 正式部署：npm run publish

脚本做了什么

  1. 切到仓库根目录
  2. 安装依赖（更偏向可复现）：
    • 如果存在 package-lock.json：删除 node_modules 后使用 npm ci
    • 否则：使用 npm install
  3. 拉取 Butterfly 最新主题到 themes/butterfly（浅克隆），并移除主题的 .git
  4. 执行 hexo clean 与 hexo generate

注意事项

  • 该脚本会重置 themes/butterfly 目录（删除后重新拉取）。如果你对主题做过“直接改主题源码”的本地修改，会被覆盖。
  • 本仓库约定：不要直接修改主题源码；尽量通过 _config.butterfly.yml 做配置化定制。
