LazyMount-Mac：让你的 Mac 拥有无限存储空间（支持 SMB/Rclone/Tailscale）

发表于28-01-2026|更新于28-01-2026|效率工具玩转 Mac
|总字数:1.4k|阅读时长:4分钟|浏览量:

TL;DR: 这是一个完全开源的 Bash 脚本，用来解决 macOS 下挂载 NAS 和网盘的各种痛点（掉线、卡顿、休眠断连）。既然苹果的硬盘卖得比金子还贵，那我们就自己动手丰衣足食。

👉 项目地址: GitHub - LazyMount-Mac (求 Star 🌟)

😫 为什么要造这个轮子？

如果你和我一样是用着 256G/512G 的 “丐版” Mac，那你一定懂这种焦虑：

  • Docker 镜像 不敢随便拉。
  • Steam 游戏 下两个就红了。
  • 本地 LLM 模型 (Ollama) 动不动几十 G，根本存不下。

虽然家里有 NAS，也有无限空间的 Google Drive，但 macOS 自带的挂载体验真的 一言难尽：

  1. Finder 也是个"垃圾"：挂载 SMB 只要以休眠，醒来必断。断了就算了，Finder 转圈能转到你强制重启。
  2. 异地访问难：在家用内网 IP，出门去星巴克得切 VPN，IP 变了挂载又得重连。
  3. 商业软件贵：Mountain Duck / CloudMounter 动辄几百块，而且很多还不支持原本的系统级协议。

所以我一怒之下搓了 LazyMount-Mac。

🛠 它能干得过付费软件吗？

我不敢说干掉所有付费软件，但在 “稳” 和 “无感” 这一块，它绝对是第一梯队。

核心特性

  • 🤖 完全无感：开机自动后台运行，并没有烦人的状态栏图标和弹窗。
  • ❤️ 心跳检测：它会像看门狗一样盯着你的网络。Wifi 断了？它暂停。连上 Wifi 了？它 3 秒内把盘给你挂回来。
  • 🚀 双模驱动：
    • SMB 模式：原生挂载，速度跑满内网带宽（我家 2.5G 内网实测能跑 280MB/s+）。
    • Rclone 模式：内置了 Rclone 集成，把 Google Drive、OneDrive、S3 这种云存储挂载成本地硬盘，还能利用缓存加速。
  • 🌍 Tailscale 自动适配：这是我最想要的功能。我在家它走 192.168.x.x，出门它自动识别并走 100.x.x.x (Tailscale)，路径完全不变！

🎮 硬核用法：它到底能怎么玩？

光挂载个文档没意思，给大家整点硬核的。

1. NAS 直玩 Steam 3A 大作

很多人觉得网盘玩游戏卡，那是你打开方式不对。
Steam 不支持直接把库建在网络驱动器上，但我们可以 “骗” 过它。

  1. 在 NAS 上以此创建一个 稀疏磁盘束 (Sparse Bundle) (Mac 的一种磁盘镜像格式)。
  2. 用 LazyMount 把它挂载到 /Volumes/Games。
  3. Steam 会把它识别为一块 物理外接硬盘。

实测：我在 NAS 上存了 150G 的《博德之门 3》，通过千兆网线直接玩，加载速度和机械硬盘差不多，完全不卡！省下的 150G 空间干啥不香？

2. 本地跑满血 AI 模型 (Ollama)

现在本地跑 LLM 很火，但像 Llama-3-70B 这种高质量模型，一个文件就 40G 起步。
丐版 Mac 根本不敢下。

骚操作：
把你的 .ollama 文件夹整个迁移到 NAS 或者挂载的 Google Drive 里。
通过 LazyMount 挂载回来，做一个软链接 (Symlink)。

这时候你再跑 ollama run llama3:70b，它会直接读取 NAS 里的数据进内存。只要你内网够快（推荐 2.5G 以上），体验和本地一模一样。

3. TimeMachine (时间机器) 永不断连

Mac 的时间机器如果是备份到 NAS，经常会因为网络波动备份失败。
LazyMount 能够保证挂载点的绝对稳定，让 TimeMachine 以为磁盘一直插在电脑上，备份成功率直线飙升。

🧐 常见问题 (Q&A)

Q: 挂载了 SMB 但是只读？
A: 这是个经典坑。记得第一次手动在 Finder 连接一次，勾选 “在钥匙串中记住密码”。脚本是利用系统钥匙串自动登录的。

Q: Tailscale 怎么配置？
A: 只要你在脚本里填的是 Tailscale 的 IP (100.x.x.x)，脚本会自动 Ping 通后再挂载。建议配合 Subnet Router (子网路由) 使用体验更佳。
