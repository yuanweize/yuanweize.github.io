🚀 Speed Up Your Downloads / 提升你的下载速度

Aria2 is powerful, but without good Trackers, BitTorrent download speeds are painfully slow.
Aria2 很强大，但如果没有好的 Tracker，BT 下载速度会慢得令人发指。

Manually copying tracker lists from GitHub every week? Ain’t nobody got time for that.
每周手动从 GitHub 复制 Tracker 列表？没人有那个闲工夫。

BTtrackers-updater handles this automatically.
BTtrackers-updater 帮你全自动搞定。

✨ Why This Tool? / 为什么选择它？

  1. Multi-Source: Fetches from trackerslist, XIU2, and animeTrackerList. Merges and deduplicates them.
    多源获取：从 trackerslist, XIU2, animeTrackerList 获取，自动合并去重。
  2. Smart RPC: It talks to Aria2 via RPC. No Restart Required!
    智能 RPC：通过 RPC 与 Aria2 通信。无需重启！
  3. Safe: Backs up your config before touching it.
    安全：修改前自动备份你的配置。

Installation / 安装

Setup a cron job, and your Aria2 will always be running at full speed.
设置好定时任务，你的 Aria2 将永远全速运行。
