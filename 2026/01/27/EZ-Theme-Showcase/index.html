🎨 Aesthetics Matter / 颜值即正义

For service panels like V2Board, user experience is often an afterthought.
对于像 V2Board 这样的服务面板，用户体验往往是被忽视的。

I created EZ-Theme with one goal: Premium UX.
我创建 EZ-Theme 的目标只有一个：极致的用户体验。

✨ Features / 特性

  1. Vue 3 Modern Stack: Fast, responsive, and smooth animations.
  2. Dark Mode: Native support for light/dark switching.
  3. i18n: Built-in support for multiple languages.
  4. Modular: Clean code structure that is easy to maintain.

If you are running a service, don’t let a bad UI drive users away. Upgrade to EZ-Theme today.
如果你在运营服务，别让糟糕的 UI 赶走用户。今天就升级到 EZ-Theme。
